# Agentworkflow

Planning and design workflow for Solomantalgo Web Design client websites.

Start a new client planning agent with [CLIENT_PLANNER_PROMPT.md](templates/CLIENT_PLANNER_PROMPT.md). Give it the client's name, project path, and known brief. [AGENTS.md](AGENTS.md) directs that agent to the shared business reference, current packages, workflow, and project plan template.
