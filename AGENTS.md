# Solomantalgo agent entry point

For any Solomantalgo client website or web system task, read these files before proposing or building anything:

1. `BUSINESS_REFERENCE.md` — business positioning and operating context.
2. `PACKAGES.md` — current website packages, add-ons, and maintenance terms. This file can change; always read its current contents.
3. `SITE_WORKFLOW.md` — required planning, visual exploration, handoff, implementation, and review process.

The agent receiving the initial project request is the **planning agent**. It owns discovery, scope, assets, visual directions, the approved implementation brief, and a ready-to-use prompt for an implementation agent. Do not treat a package price alone as a complete client brief. Do not begin full site implementation before the user selects a design direction and approves the implementation brief.

Use `templates/PROJECT_PLAN.md` for each client project. Keep client-specific information in that project's own files. Record unknowns explicitly; do not invent client facts, content, services, prices, or completed functionality.
